# astra

**Blox Fruits Sniper**

A lightweight fruit-sniping tool designed for a smoother and smarter fruit-hunting experience.

## Features

- **Webhook** – Receive notifications about fruit discoveries.
- **Smart Hop** – Automatically searches for better fruit opportunities across servers.
- **Owned Fruit Detection** – Skips fruits you already own.
- **Fruit Cap Detection** – Skips fruits when your inventory is capped.
- **Priority Fruits** – Add specific fruits to your priority list.
- **Less Lag** – Optimized for smoother performance.
- **Free** – Completely free to use.

## Performance

ASTRA focuses on efficient server searching and reduced unnecessary processing.

## Disclaimer

ASTRA is an independent community project and is not affiliated with Roblox or the Blox Fruits developers. Compatibility and detection status are not guaranteed.
